# SuperGenericBros

Startprojekt för **Examination 2** i C#-kursen för Spelutvecklare på Nackademin.

Repositoryt innehåller materialet som behövs för examinationsuppgiften:

- `SuperGenericBros/` – Unity-projektet som ska användas i uppgiften
- `Examination 2.pdf` – instruktioner och krav för examinationen

## Kom igång

1. Ladda ner eller klona repositoryt.
2. Läs igenom `Examination 2.pdf`.
3. Öppna projektet `SuperGenericBros` i Unity Hub.
4. Kontrollera att projektet öppnas utan errors.
5. Följ instruktionerna i examinationsuppgiften.
6. Det finns mer assets än vad du kan använda, så fastna inte där. 

## Viktigt

Arbeta i en **egen kopia** av projektet.

Skapa ett eget repository för ditt arbete och pusha dina ändringar dit.

Ändra inte filerna i detta repository.

## Syfte

Projektet används som startpunkt för den individuella inlämningsuppgiften där du ska vidareutveckla, färdigställa, bygga och leverera ett spel i Unity.
